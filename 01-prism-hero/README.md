# Prism Hero

A crystal refraction hero frontend.

## Installation

```bash
npm install
```

## Running the app

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## What it demonstrates

This project demonstrates a 3D scroll-driven crystal refraction effect using Three.js, React Three Fiber, Framer Motion, and Next.js. The `components/ui` structure is used since shadcn's generator and the `@/components/ui/...` imports expect this specific folder convention.
